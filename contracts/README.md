# Runtime Contracts

Este diretorio documenta contratos minimos usados no runtime atual:
- `runtime_tool_call.schema.json`: envelope de chamada unificada.
- `tool_inputs.schema.json`: subset de tools e inputs esperados.
- `journal_event.schema.json`: formato base de eventos de journal.
- `simulator_payload.schema.json`: payload minimo para mapeamento simulador JSON -> parametros GN.

Objetivo: manter chat interno, bridge addon e MCP externo sincronizados.
